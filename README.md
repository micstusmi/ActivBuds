# fitbuds
Now I'm wanting to make a separate application called fitbuds. There will be multiple components to it.

Will be an ios / android app that will be for mobile devices and will be user's location-based and the other part will be a website that will integrate with the app. The website will mostly be for the advertisers. The advertisers will be split up into 2 different types. 1. type is brick and mortar gyms (or other types of fitness / activity venues), and, also, some will be independent gyms and some will be franchises with a head office. 2. Will be individual personal trainers. Basically, the purpose of the app is for user's to sign up on the app to be able to find a fitness or activity partner and, to be able to have the app make an income, the gyms, activity centres, personal trainers should be able to advertise on the app to entice user's to come to their facilities to gain new customers, or, personal trainers can advertise on the app too. To start off with I want to make the website. I'll need to make tables for the SQL. I'll need to make pages for the website in php and the advertisers need to be able to sign up authorised staff members to be able to integrate with the website and see a dashboard of how many paid or free ads they are getting from using the app and how many user's are seeing their ads and how many user's are clicking on their ads. They also need to be able to see how much they are spending on the app and they need to be able to pay more or less in order to get more ads or better ad placement compared to other advertisers. The ads also need to be location based so that they can select a kilometre radius from either where they are currently or a selected kilometre radius from their brick and mortar location. The app will need to be able to provide real-time pricing to the advertiser when they adjust the kilometre radius, the ad frequency and the ad placement in relation to other advertisers and where in the mobile app for example, when browsing user profiles, when messaging, is the ad a static ad or dynamically revolving on a virtual carousel or a video, etc. Perhaps the advertisers should be able to choose their own media or outsource getting the advertising made by a fitbuds 3rd party contractor. Perhaps the 3rd party contractors should be able to sign up with fitbuds in order to be able to advertise their services on fitbuds or perhaps we could just re-direct the advertisers to a service like airtasker or fiverr to get quotes for the work? Is that enough information for now for us to start a prototype for the website part of the app?
